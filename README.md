# Anatomapp

Telegram Mini App для `@Vmeda_anatom_bot`. Основной production-адрес — бесплатный системный
домен Vercel `https://anatomapp.vercel.app`; купленный домен для запуска приложения не требуется.
Railway-сервис в проекте бота остаётся независимым резервом.

## Production

Vercel раздаёт интерфейс и серверные функции `/api/auth/telegram`, `/api/state`, `/api/users`.
Прогресс и старые аккаунты продолжают храниться в Supabase. `/api/leaderboard` добавляет данные
общей Postgres-базы бота, а интерфейс объединяет их со старыми участниками без обнуления рейтинга.

Переменные Vercel перечислены в `.env.example`. Секреты добавляются только в настройках проекта и
никогда не помещаются в HTML или Git.

## Railway fallback

`server.js` может раздавать тот же интерфейс на Railway и проксировать `/api/auth/telegram`,
`/api/state` и `/api/leaderboard` в API бота. Переменные резервного сервиса:

- `UPSTREAM_API_URL` — публичный URL API бота;
- `ADMIN_TELEGRAM_IDS` — Telegram ID администраторов через запятую;
- `PORT` Railway назначает автоматически.

Основной или резервный адрес указывается в `ANATOM_WEBAPP_URL` у сервисов бота и API. Бот обновляет
кнопку меню при каждом запуске, поэтому ручная настройка BotFather не требуется.

Локальный запуск: `npm start`, проверка: `npm run check`.

## Хранение данных

На основном Vercel-адресе Telegram ID, профиль и учебный прогресс сохраняются в Supabase. Local
Storage используется как офлайн-кэш; перед первой записью приложение загружает облачное состояние
и объединяет данные, поэтому пустое устройство не обнуляет прогресс. На резервном Railway-адресе
используется общая Postgres-база бота.
