# Anatomapp

Telegram Mini App для `@Vmeda_anatom_bot`. Production разворачивается отдельным Railway-сервисом
в одном проекте с ботом; Vercel и пользовательский домен для запуска приложения не требуются.

## Railway Mini App

`server.js` раздаёт интерфейс и проксирует `/api/auth/telegram`, `/api/state` и
`/api/leaderboard` в API бота. Благодаря одному origin Telegram-авторизация и синхронизация
прогресса не зависят от CORS или внешнего домена.

Переменные сервиса:

- `UPSTREAM_API_URL` — публичный URL API бота;
- `ADMIN_TELEGRAM_IDS` — Telegram ID администраторов через запятую;
- `PORT` Railway назначает автоматически.

После смены адреса сервиса укажите его в `ANATOM_WEBAPP_URL` у сервисов бота и API. Бот обновляет
кнопку меню при каждом запуске.

Локальный запуск: `npm start`, проверка: `npm run check`.

## Хранение данных

Telegram ID, профиль и учебный прогресс Mini App сохраняются в общей Postgres-базе бота через
`/api/state`. Local Storage используется как офлайн-кэш: при первом входе с существующего
устройства накопленный прогресс отправляется в Railway.

Supabase остаётся подключённым для совместимости со старыми email-аккаунтами и их рейтингом на
время перехода. Серверные ключи, токен бота и секрет сессии нельзя добавлять в HTML или коммитить.
